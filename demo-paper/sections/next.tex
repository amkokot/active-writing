\section{Try the notebook, then make this yours}\label{sec:next}
Open Notebook for a guided question and an unrun experiment. Run it only after
reading the code and choosing a Python interpreter. Its table and plot compare
partial sums for several values of $r$. A finite calculation illustrates the
formula; it does not prove it for every $n$.

An external chat can think while you work elsewhere. Copy a prompt, move to the
next queue item, and paste the response back if worth keeping. A folder-aware
agent can save directly into the notebook using Aw's guarded tools. No cloud
chat is called automatically.

Use the manuscript menu to make a version or add an Overview. Research notes
are the default. Choose Publication draft when you want incremental proposals,
human review and wording locks. Use the folder button to create a separate
project, and keep this example as a reference.

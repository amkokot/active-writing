# Welcome project

Open `main.tex`. `overview.tex` is a second independent document, and `sections/`
contains the main document's included source. These are ordinary LaTeX files.
Upload the folder to Overleaf with `main.tex` selected to compile it normally.

The companion Aw notebook is created locally during setup, outside this folder.
See the app's `docs/GETTING_STARTED.md` for a walkthrough. No cell runs during setup.
Make a new project for your own work; app updates may replace the template files.

The manuscript menu pins the short Overview and the current Research notes. Try
a comment and a reply, then use Next to return to its passage. Make a new notes
version and copy a selected conversation to see how notebooks follow versions.
The three notebook cells are intentionally unrun. Python is optional; notes,
Markdown/math and saved displays can be read without it.

For interactive plots beyond the simple experiment, see
`docs/RESEARCH_VISUALS.md`; `awResearch.ts visuals` gives agents a small offline
catalogue. To practise writing for publication, create a separate Publication
draft; the notes template does not impose that review workflow. Two-computer
sync, local helpers and hosted sharing can all be skipped (see `docs/MODULES.md`).

# Welcome project

Open `main.tex`. `overview.tex` is a second independent document, and `sections/`
contains the main document's included source. These are ordinary LaTeX files.
Upload the folder to Overleaf with `main.tex` selected to compile it normally.

The companion Aw notebook is created locally during setup, outside this folder.
See the app's `docs/GETTING_STARTED.md` for a walkthrough. No cell runs during setup.
Make a new project for your own work; app updates may replace the template files.

\section{Start with a small edit}\label{sec:start}
Change a sentence in this paragraph. A blank line starts another paragraph;
one source-line break does not. Source edits save back to this ordinary TeX file.

Use All sections, This section or Block window to choose how much text surrounds
your current passage. Drag the central divider to give either pane more room.
The rendered-text preview is available without a TeX installation. Compile shows
the real PDF when a TeX compiler is installed.

Select a phrase to ask a question, request alternatives, leave a comment or save
a passage for later. Comments stay in the priority queue until resolved. Show in
preview follows the source passage; double-click a preview passage to return.

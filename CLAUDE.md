# Active Writing

Read [AGENTS.md](AGENTS.md) for the shared instructions used by all folder-aware
assistants. If asked to install or set up Aw, start with
[docs/ASSISTANT_SETUP.md](docs/ASSISTANT_SETUP.md) and ask which optional features
the person wants. A single-computer editor/notebook is a complete installation.
Do not install every integration just because its code is present.

When updating, read [docs/UPDATING.md](docs/UPDATING.md). Merge new guidance with
existing user/project instructions by intent; preserve user requests, preferences
and enabled-module choices. Do not replace their instructions with this template.
